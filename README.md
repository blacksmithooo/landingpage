# landingpage

Blacksmith landing page, built from the "Landing page" frame in the BCJ – Brand Figma file.

**Live preview:** https://blacksmithooo.github.io/landingpage/

Or open `index.html` in a browser — no build step.

## Page

A long-form page with a product-site structure: promo bar, sticky header,
hero panel, intro, services carousel, 4-week process, client quotes, a
spotlight on the pod, selected work, a contact sign-up and footer. Styles are
in `styles.css`, behaviour (smooth scrolling, menu, carousel, scroll reveals)
in `main.js`.

Client quotes and work tiles are placeholders. Swap in real quotes and case
studies before sharing it.

## Fonts

The page uses the brand typefaces from [`fonts/`](fonts/): Suisse Works
(headlines), Suisse Int'l Medium (body text) and Suisse Int'l Mono (labels
and buttons).
