# landingpage

Blacksmith landing page, built from the "Landing page" frame in the BCJ – Brand Figma file.

**Live preview:** https://blacksmithooo.github.io/landingpage/

Or open `index.html` in a browser — no build step.

## Fonts

The page uses the brand typefaces from [`fonts/`](fonts/): Suisse Works
(headline), Suisse Int'l Medium (column text) and Suisse Int'l Mono (labels
and buttons). Sizes, line heights and letter spacing match the Figma frame,
which is 6291px wide; the layout scales with it at any screen width above
720px and stacks into one column on phones.

## Studio page

[`studio.html`](studio.html) (live: https://blacksmithooo.github.io/landingpage/studio.html)
is a long-form page with a product-site structure: promo bar, sticky header,
hero panel, intro, services carousel, 4-week process, client quotes, a
spotlight on the pod, selected work, a contact sign-up and footer. It uses the
same fonts and colours as the landing page, with rounded panels and cards.
Styles are in `studio.css`, behaviour in `studio.js`.

Client quotes and work tiles are placeholders. Swap in real quotes and case
studies before sharing it.
