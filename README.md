# landingpage

Blacksmith landing page, built from the "Landing page" frame in the BCJ – Brand Figma file.

**Live preview:** https://blacksmithooo.github.io/landingpage/

Or open `index.html` in a browser — no build step.

## Fonts

The design uses Suisse Int'l, Suisse Int'l Mono and Suisse Works, which are licensed.
Add the woff2 files to `fonts/` (`SuisseIntl-Medium.woff2`, `SuisseIntlMono-Regular.woff2`,
`SuisseWorks-Regular.woff2`) to use them; until then the page falls back to Inter,
JetBrains Mono and Newsreader from Google Fonts.
